# 🕊 Голубь

**Свободный, локальный и зашифрованный мессенджер, разработанный ИИ**

Работает без интернета, без серверов и без регистрации по номеру телефона.
Просто запусти на телефоне в Termux — и общайся с теми, кто рядом.

## ✨ Возможности

- 💬 **Личные чаты, группы и каналы** — как в больших мессенджерах, только локально
- 🔒 **E2E-секретные чаты** — ECDH P-256 + AES-GCM прямо в браузере, сервер видит только base64
- 🎙 **Голосовые сообщения** — запись, отправка, воспроизведение
- 📎 **Отправка файлов** — фото, видео, документы, несколько сразу, скачивание с превью
- 🖼 **Стикеры** — с паками, официальными значками
- 📊 **Опросы** — с несколькими ответами и анонимностью
- 📌 **Закреплённые сообщения, реакции, ответы, редактирование**
- 📞 **Аудиозвонки** через WebRTC P2P
- 👥 **Права в группах** — админ, приглашения, писать, закреплять, удалять
- 🔗 **Приглашения по ссылке** — `/j/<hash>` для групп и каналов
- 🐌 **Медленный режим** — антиспам в чатах
- 📁 **Папки** — разложить чаты по категориям
- 🔔 **Уведомления** браузера
- 🌙 **Тёмная / светлая тема**
- 📱 **Адаптивность** — один интерфейс для телефона, планшета и ПК

## 🔐 Безопасность

- Пароли — **PBKDF2-SHA256** (200 000 итераций, соль на пользователя)
- Сообщения и файлы на сервере — **Fernet** (AES-128-CBC + HMAC-SHA256)
- Секретные чаты — **E2E**: ключи генерируются и хранятся только на устройствах пользователей
- Никаких внешних серверов: всё лежит в папке `data/` рядом с `app.py`

## 🌲 Где использовать

- **В лесу, в походе, на фестивале** — там, где нет интернета, но есть Wi-Fi между телефонами (hotspot).
- **В деревне, на даче** — где мобильный интернет медленный или отсутствует.
- **На работе в изолированной сети** — для общения без выхода во внешний интернет.
- **В школе, офисе, общаге** — как альтернатива интернет-мессенджерам в общей сети.
- **Для обучения** — показывает, как устроены WebRTC, WebCrypto и E2E изнутри.
- **Для ивентов, конференций** — гости подключаются к локальному Wi-Fi и общаются внутри.

> Достаточно одного устройства с Termux и Wi-Fi-точкой доступа. Остальные подключаются к нему через браузер.

## 📱 Запуск в Termux

### 1. Установить Termux

Скачай из **F-Droid**: [f-droid.org/packages/com.termux](https://f-droid.org/packages/com.termux/)  
(версия из Play Store устарела и не подходит)

### 2. Установить зависимости

```bash
pkg update && pkg upgrade -y
pkg install python git -y
pkg install python-cryptography -y
pip install flask
```

### 3. Скопировать проект

```bash
termux-setup-storage
cd ~
git clone https://github.com/s05623821-creator/messenger-D-ove-.git messenger
cd messenger
```

### 4. Запустить

```bash
python app.py
```

Увидишь:

```
Голубь v2.3 запущен: http://0.0.0.0:8080
```

### 5. Открыть

- **На этом же телефоне:** `http://127.0.0.1:8080`
- **С другого устройства в той же Wi-Fi-сети:** `http://<IP-телефона>:8080`

Узнать IP телефона:

```bash
ifconfig 2>/dev/null | grep "inet " | grep -v 127.0.0.1
```

### 6. Первый вход

- **Аккаунт разработчика** создаётся автоматически: `@stepan` / `gtfdes1M#`
- Или зарегистрируй новый через вкладку «Регистрация»

## 📞 Звонки — важное

Аудиозвонки (WebRTC) работают **только** на:

- `http://127.0.0.1:8080` (localhost)
- `https://...`

**На `http://192.168.x.x` браузер блокирует микрофон** — это политика Chromium/Safari, не баг приложения.  
С телефона по IP звонить не получится, но чаты/файлы/секретные чаты работают отлично.

## 📁 Структура

```
messenger/
├── app.py                  — сервер Flask
├── requirements.txt
├── templates/
│   └── index.html          — единый HTML-каркас
├── static/
│   ├── style.css           — оформление
│   ├── app.js              — вся логика клиента
│   └── icon.svg            — иконка мессенджера
└── data/                   — создаётся автоматически
    ├── messenger.db        — SQLite со всеми данными
    ├── secret.key          — ключ шифрования сервера (НЕ коммитить!)
    ├── session.key         — секрет сессий (НЕ коммитить!)
    ├── avatars/            — аватарки
    └── files/              — сообщения, вложения, стикеры
```

- **Frontend:** Vanilla JS, WebCrypto API, WebRTC, Notification API
- **Без зависимостей от CDN** — всё работает в локальной сети
